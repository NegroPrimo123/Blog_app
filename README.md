# Blog_app

Аутентификация (User Routes)
POST /api/auth/register - Регистрация нового пользователя

POST /api/auth/login - Авторизация пользователя

GET /api/auth/me - Получение информации о текущем пользователе (требует авторизации)

Посты (Post Routes)
GET /api/posts - Получение всех постов (доступно без авторизации)

GET /api/posts/:id - Получение конкретного поста по ID (доступно без авторизации)

GET /api/posts/:postId/images - Получение изображений поста (доступно без авторизации)

POST /api/posts - Создание нового поста (требует авторизации)

PUT /api/posts/:id - Обновление поста (требует авторизации)

DELETE /api/posts/:id - Удаление поста (требует авторизации)

POST /api/posts/images - Добавление изображения к посту (требует авторизации, загрузка файла)

Комментарии (Comment Routes)
GET /api/comments/post/:postId - Получение комментариев для поста (доступно без авторизации)

POST /api/comments - Создание комментария (требует авторизации)

DELETE /api/comments/:id - Удаление комментария (требует авторизации)

Лайки (Like Routes)
GET /api/likes/count/:postId - Получение количества лайков для поста (доступно без авторизации)

POST /api/likes/toggle - Переключение лайка (требует авторизации)

GET /api/likes/check/:postId - Проверка, лайкнул ли текущий пользователь пост (требует авторизации)

Статические файлы
GET /uploads/:filename - Получение загруженных изображений (доступно без авторизации)

GET /uploads/thumbnails/:filename - Получение миниатюр изображений (доступно без авторизации)
